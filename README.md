# Cloud Compliance Risk Assessment – NIST CSF 2.0

## Project Overview

This simulated portfolio project demonstrates a cloud compliance risk assessment for a fictional organization using the NIST Cybersecurity Framework (CSF) 2.0.

The assessment identifies, evaluates, prioritizes, and monitors security and compliance risks across cloud services.

## Key Results

* Total risks assessed: **12**
* Critical risks: **3**
* High risks: **8**
* Medium risks: **1**
* Open risks: **12**

## Assessment Scope

The project covers:

* Cloud identity and access management
* Cloud storage and databases
* Backup and recovery
* Security logging and monitoring
* Virtual machine patching
* Data classification and retention
* Incident response
* Third-party access

## Deliverables

The Excel workbook contains:

* Risk Register
* Risk Scoring Model
* Compliance Dashboard
* Project Overview
* Evidence Tracker
* NIST CSF 2.0 Control Mapping
* Mitigation Actions and Target Dates
* Residual Risk Ratings

## Tools and Frameworks

* NIST Cybersecurity Framework 2.0
* Microsoft Excel
* WPS Spreadsheets
* Governance, Risk, and Compliance (GRC)
* Cloud Security Risk Assessment
